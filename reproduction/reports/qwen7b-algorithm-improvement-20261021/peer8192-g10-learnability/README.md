# 8192题真实 G10 的可学习性与训练构组统计

本报告分析预先冻结的 NQ 8192 题，每题由原始5条＋新独立 seed 的5条组成真实 G10。没有重新选题、生成响应、读取 tensor/模型/探针分数，也没有提交或改变训练作业。该 cohort 是补充当前受控训练集的数据，**不能称为从未参与最初169028题 warmup 的新题**。

SHA绑定的 ownEM 通过验收的 groups 与四个 Prefix20 投影文件均在 HPC3 CPU 读取；仅本汇总和代码回到本地。实测分析17.64秒完成，前一次观察已到81920条因果输入签名，后一次观察 complete，随后重新读取 complete 与全部6个不可变源码文件 SHA。没有 failure，原 CPU 进程已退出。

## Prefix20 完全相同因果输入的冲突

“相同输入”忽略 qid/tid/seed/run/文件定位，但保留冻结官方actor revision、初始prompt、完整真实因果context、原位置0..L-1、context attention、question/policy gather位置，以及293槽mask/位置和实际Prefix20 token/长度。未把不同工具上下文粗略视作相同输入。本批中token-only与完整因果签名得到的簇恰好相同；这只是该8192题的实测结论。

| 统计口径 | 实测 |
|---|---:|
| 同题10条中存在任意重复的题 |1960/8192=23.9258%|
| 全10条完全相同的题 |0/8192|
| 有重复同伴的轨迹 |5140/81920=6.2744%|
| 超出每个输入首条的重复轨迹 |2863/81920=3.4949%|
| 完全相同输入对／全部同题无序对 |3665/368640=0.9942%|
| 完全相同输入且EM相反／全部正确-错误对 |505/57765=0.8742%|
| 真G10 Mixed且至少一对完全相同输入但EM相反 |307/3489=8.7991%|

每题不同输入数1..10的题数为 `[0,0,1,4,11,39,160,396,1349,6232]`。实际81920条中有84条跨多个真实工具context、1条真实短Prefix20，均使用原mask/位置/terminal边界，不合成未来token。

对每个完全相同输入簇，假定一个固定、确定性的轨迹概率函数，标签数k/n对应的经验最小BCE为 `n H(k/n)`。本有限训练样本只由这些冲突带来的均值下界：

- 所有真实G10轨迹：**0.00648009 nat/trajectory**。
- 仅真实Mixed G10题：0.01521494 nat/trajectory。
- 当前实际四随机G5视图、题权重1的真实BCE reduction：**0.00560062 nat/trajectory**。

这个下界很小，**不能据此把当前低验证BA归因于Prefix20完全重复而不可学**。它也不能证明其余不同prefix足以预测后续正确性；相近但不完全相同输入、特征质量、目标/模型拟合与泛化仍需真实同backend验证。该数不是测试Bayes下界、不是Mixed BA上限、也不是跨不同参数快照的训练前loss下界；只覆盖本批观测输入、同题精确冲突，以及指定确定性函数。BCE单位为自然对数，未包含three-event或rank loss。
