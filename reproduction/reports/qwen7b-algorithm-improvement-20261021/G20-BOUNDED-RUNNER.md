# Authentic G20 matched probe comparison

The independent runner consumes the accepted original G5 plus three real extra-G5 events: 6,528 questions and 130,560 unique own trajectories. It preserves the E1 raw/EMA probe, readout, Adam step 10,464, canonical source-rank RNG and all four source-rank state records. It updates no actor and initializes no probe parameter again.

Random and strict globally balanced arms inherit **exactly the same 136 batches of 48 questions and their order from the actual G10 comparison**. Preparation verifies that the G20 pool's first ten IDs/labels exactly preserve that accepted G10 pool. Every inherited batch must still contain at least 24 heterogeneous G20 questions; impossible input fails before submission. Each original question contributes four unique authentic G5 views, each weighted 1/4. In the balanced arm, Mixed and nonMixed view count and weighted mass are both exactly equal.

The complete-question loss uses 20 logits per original question and strict G5 own EM after subset selection. The two-pass logit VJP retains one five-trajectory transformer graph at a time. It replays each microforward's RNG/native buffers and requires bit-identical recomputed logits before any Adam write. A first actual update is repeated from the same full source state before acceptance; a full durable checkpoint precedes external evaluation. Later resume rejects a missing or older checkpoint when later progress/update intent exists.

The arms use the same E1, question order, 136 Adam updates, LR 5e-6, trajectory plus three-event objective and evaluation identities. They use native L26/Q273/Prefix20 features and the original block27/readout geometry. They are distinct from the new peer NQ HF-batched feature branch. Compared with G10, authentic pool size and forward compute increase; total trajectory compute is not equal. Diagnostic512 and the precommitted fresh-G5 validation2048 remain fixed, with no final-pool payload read.

Local qualification consists of 18 focused tests: complete20 joined-gradient/VJP agreement, Adam/EMA continuity, actual stochastic/native-state replay, exact fullstate continuation, wrong10-source and changed-second-pass rejection, G20 loss own-ID/weight semantics, combination grouping, and preservation of the original G10 question order. These tests do not assert GPU qualification; real jobs must supply the first-update replay, continuing cursor, actual checkpoint and final validation evidence.

The deployment helper stages a published import closure in 4 KiB chunks. Every control command is below 16 KiB. It submits two isolated normal/acd_u jobs, one H100/8 CPUs/64 GiB each for two hours, without dependencies. Existing IDs and unknown submission intents block duplicate submission. No active source or existing task is changed.
