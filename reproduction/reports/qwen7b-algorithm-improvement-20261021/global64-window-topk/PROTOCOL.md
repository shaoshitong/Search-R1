# Matched global64 TopK-ramp: current-only versus detached2018 window

The original four global128 MSE/BCE factorial entries remain independent. Their staged128 TopK fifth entry stays unrun. This new pair changes neither the old runtime nor an existing job.

Both new cells use copied official layer15, authentic Prefix80, identical2048-position packed head/init seed9137, global64/local32/micro8/accum4, LR5e-6 and EMA.9995. Each epoch visits all8192 questions once in independently shuffled order, selecting one random ownG5 from ownG10 without consulting EM. Ten epochs are1280 global batch attempts. The common CPU-accepted92160-row token fixture is reused read-only; no hidden-feature cache or new rollout is generated.

`current64` uses only the current64 graph-carrying logits: N64, K=ceil(64×500/2018)=16. `window2018` prepends the most recent up-to1954 detached historical raw logits to current64, for total N_eff≤2018 and K=ceil(N_eff×500/2018), reaching K500 at a full window. Prior entries for current question IDs are removed before FIFO assembly so a window has unique question IDs. Labels always describe each stored selected ownG5. The cache stores identities, true EM, detached floats and the actual raw Adam-update version; it contains no features or graph tensors.

Both use the exact same `group_topk_losses.precision_at_k_ramp`: b=min(K,totalMixed), C*=best sizeK score sum among label-optimal selections, L=relu(gamma*b+TopK(s−gamma*y).sum()−C*)/(gamma*K), gamma1. C* retains current-logit gradients. Only current logits have autograd; old logits remain detached constants. Current logits are gathered with autograd across both ranks before the one global objective. The training gradient is scaled by N_eff/64 to avoid dilution as the detached window grows; the unscaled bound loss and scaled training loss are logged separately. This is an explicit scaling heuristic, not an unbiased stale-gradient estimator.

Backward runs on both ranks for synchronization. Adam and EMA are both skipped when unscaled loss is zero OR all gradients on the current64 logits are zero (a constraint supported only by cached entries). Old optimizer moments remain intact. Batch attempts, actual Adam updates, EMA updates, satisfied-margin skips and cached-only zero-current-gradient skips are separate counters. Cache commit runs after every attempt and retains the pre-update score version. Checkpoints include raw/EMA/Adam, both-rank RNG, exact sampling plan, complete queue state and hash, raw score version and the last loss window; ordinary checkpoint state has no pending queue batch.

Primary comparison is fixed viewed-independent2048 ownG5 Top512 true Mixed, with exactly matched fixed train2048 G5 diagnostics. Scores are unbounded ranking logits (sigmoid values for report ordering), not calibrated Mixed probabilities; BA at0.5 sigmoid is secondary and predeclared. Each epoch also performs a no-grad frozen-window audit: current raw logits are recomputed online for the stored identities only; EM and cached scores never enter its model callback. It reports driftδ, TopK overlap, old/fresh precision, the exact C* ramp and the finite-window `L_fresh≤L_cache+2δ/gamma` certificate. This is neither a final-pool result nor a future-pool guarantee. The audit never refreshes cache scores or changes parameters.

All source and entries are published before staging. Resources are two GPUs,12CPUs,128GiB,2h, initial acd_u/normal. Root owns Slurm submissions. The deployer only stages immutable files/entries and freshly rehashes the already independently accepted Prefix80 fixture. Final4096 remains untouched.
