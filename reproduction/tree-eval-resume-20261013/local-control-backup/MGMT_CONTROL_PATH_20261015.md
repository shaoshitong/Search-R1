# Optional task-local management SSH reuse

`ssh_retained18.py` accepts `TREE_MGMT_CONTROL_PATH` only for the outer Mac-to-`mgmt-host` SSH connection. When unset, the complete route argv is identical to the prior helper. When set and valid, only `ControlPath=<literal path>`, `ControlMaster=auto`, and `ControlPersist=600` are added. The `mgmt-host`/en0 configuration, `curve25519-sha256`, `IPQoS=none`, identity checks, strict inner host checks, and retained `10.33.0.18` route remain as published in base commit `d5ddeff4e24367ff98504850cf4ef00342f81b7d`.

The path must be absolute, literal, at most 80 filesystem bytes, and contain no whitespace/control characters, percent/dollar expansion tokens, or non-simple socket filename. Its direct parent must be a real directory owned by the current user with mode 700, directly beneath `/tmp` or the system temporary directory, and named `tree-mgmt-` plus at least six ASCII letters, digits, underscores, or hyphens. Symlink parents/socket paths, existing non-sockets, and sockets owned by another user are rejected. The length bound leaves room for OpenSSH's temporary bind suffix on macOS.

Use only a freshly created directory for this Tree observer task, or this task's previously created directory/socket; never borrow another task's master. The controller's current `/tmp/tree-mgmt-3fw9a1ab/control` form is accepted if ownership and mode still match. A fresh directory can be prepared by the controller with `mktemp -d /tmp/tree-mgmt-XXXXXXXX` (mode 700) and a `control` filename within it. The helper itself does not create directories or proactively start a master. `ControlMaster=auto` may create a task master during the controller's next authenticated invocation, or reuse this task's existing one.

Minimal opt-in deployment: invoke this isolated checkout's `ssh_retained18.py` with `TREE_MGMT_CONTROL_PATH=/tmp/tree-mgmt-3fw9a1ab/control` and the controller's existing read-only command. Importing the isolated helper's `route`/`run` with that environment is also supported. No current entry was overwritten by preparation/publication. Leave the variable unset for the prior argv. Do not change global SSH/VPN/route/auth configuration or copy credentials.
