# V5：历史曝光机制检验与创作者博弈修订

分析日期：2026-11-05（北京时间）。项目定位：课程研究项目。本轮复用已校验公开元数据，执行新的预测诊断与整数博弈计算；没有真人实验、AI采用随机化、媒体下载或gated数据访问。

## 研究结论

V3中“历史曝光份额明显优于数量模型”不应直接解释为平台奖励老账号。本轮得到的证据更保守：目标作品集合自身的历史具有很强预测价值；同账号跨旧作品信号只有小幅、集中且跨账号不稳健的改善。现有数据不能区分创作者类型、账号资本、题材、受众或作品质量，也不能识别账号优势能否跨身份迁移。

新发布作品的首日任务中，目录库存与近期发布特征又优于本轮定义的旧作品历史率模型，增益主要来自训练已见/未见账号组间份额校正。因此V3的预测排序并非普遍规律。

理论应保留持续异质性与作品状态，把不可转移账号资本作为待检验的机制分支；不把历史预测器的系数当算法政策参数。账号资本的一期连续推导在其假设下成立，但真实整数作品及每账号最低内容要求会改变均衡，甚至出现无纯均衡条件。单方AI降本的方向性预测也必须限定适用域。

## 一、问题与证据标准

本轮检验五项问题：历史优势是否只是在记住旧作品；共享信息能否跨作品预测；数量在已有历史之后是否还有新增预测价值；现有公开数据是否能识别可转移能力与不可转移账号资本；连续博弈预测在整数和最低内容约束下能保留多少。

历史基线隐含逐账号训练份额，KuaiRand为6,509个份额自由度，KuaiRec为866个；与只有1–3个共同参数的数量模型使用的信息不同。它在短期留出期胜出具有预测意义，但不是因果重要性排序。训练和测试使用同一批老视频，且约87%/95%的入选账号仅有一个入选视频，数量模型无法区分大量同数量账号。状态依赖与未观测异质性的区分见[Heckman（1981）原章](https://eml.berkeley.edu/discrete/ch3.pdf)。

所有新研究都明确为探索性：V3总体结果已知；各主协议在新分析前固定，功能smoke后的数量对照追加有记录；没有称为独立预注册实验。跨seed、方向和时间起点复用数据，不当作新增独立样本。身份错配是观测性负对照，不是账号随机分配的因果检验。

## 二、KuaiRand：小幅、集中的跨作品信息

复用[KuaiRand官方数据](https://kuairand.com/)，仅tab=1。元数据确定849个多作品账号、1,922个旧视频；不按未来曝光选作者。每账号平衡分A/B，10个固定seed、两个方向、三个滚动起点，共60个单元。历史窗5日、校准2日、测试3日，九个互不重叠测试日期共有25,559条独特曝光；255,590次评分是重复预测这些事件。

只用A普通历史拟合内容数量、随机观看反馈代理与年龄基准，再将A的实际/预期曝光比收缩到1，作为B内容权重的乘数。B校准期只选择公共收缩与指数，B测试只评价；所以是目标测试期留出，不是完全没有使用B普通曝光。随机观看反馈不是内在质量；全月未来统计未使用。

|---|---:|
| 线性数量＋反馈＋年龄 | 6.55461 |
| 自由数量＋反馈＋年龄 | 6.53443 |

迁移相对内容基准差值−0.03653，固定预测下的账号聚类重采样95%区间为[−0.09682,+0.02490]。三个时间起点及十个seed的点估计均改善，但复用同一批数据，不是十三次独立复制。正确映射比200次预定匹配身份错配都好；错配平均损失6.53215，仍不能写成因果p=0。

事后固定预测影响诊断揭示集中度：678个测试有曝光的账号中，121个损失贡献改善、557个变差。排除曝光最高5个账号的评分贡献后，迁移差值反向为+0.01335；没有重拟合或重新归一化，不能将其描述为移除大账号后的新市场反事实。

目标自身历史远强于A迁移，但B模型有更多目标信息，也可能更精确地测量共享类型；不能把损失差按百分比因果分解为“作品效应”和“账号效应”。自由数量迁移相比固定线性数量只改善−0.00579，区间[−0.02247,+0.01311]，没有建立凹数量形式在历史信息之外的稳健必要性。

## 三、KuaiRec：复现的不稳定性与新作品补充

复用[KuaiRec官方逐日元数据](https://github.com/chongminggao/KuaiRec)。固定63天均有记录且首日已上传的925个旧视频，其中46个多作品账号、104个作品可做跨作品检验。该样本利用未来行存在性，属于回顾性存活面板；没有把缺失item-day补成零。

原协议锁定四个时间起点，每个14日历史、7日校准、7日测试；不看测试改选时间。主粗迁移损失3.8162，身份错配参考秩0.061，没有达到方案中的0.05参考线。内容残差迁移作为明确的secondary，损失3.5563，相对内容基准3.6814有点改善，但主要由第一个窗口驱动；按四个起点整块重采样的区间仍跨零。不能用secondary的有利总体值替代不稳健的主结果。

B自身历史损失约3.3012，信息更丰富。同账号跨作品关联在两个数据集都有部分点改善，但不能称为跨平台（两者均来自快手）、跨AI环境的强复制。两组损失的候选池、指标规模不同，不可直接横比大小。

### 新发布作品首日：目录数量有预测信息，但主要在校正组间份额

补充分析先冻结新协议，沿用四组14/7/7日窗口，仅取源中实际存在上传日记录的作品；首日是上传自然日而非完整24小时，没有日内上传时刻控制；没有将缺行补零，也不使用目标作品任何反馈。共4,315部独特测试新作品，795部来自训练窗见过的账号，3,520部来自训练窗未见账号。“未见”不是新注册，不能称为真实新账号冷启动。show_cnt合计1,869,444,356，只作评分权重，不是等量独立样本。

Q只计训练截止时已经在源数据出现的目录作品，F计其中过去14日的上传数；H仅从训练开始前已上传旧作品的实际观察item-days计算平均曝光率，无旧历史回共同先验。所有模型共用训练首日作品学到的时长基准。公共指数与收缩只用校准新作品选择，测试只评价；每天在共同的、实际观察到首日行的作品池内归一化。该池是被源数据收录的条件样本，不是全平台新作分母。

## 四、现有数据能与不能识别什么

| 对象 | 本轮证据与判断 |
|---|---|
| 同目标作品历史的预测性 | 两组旧作品检验中很强；不是历史的因果效应 |
| 同账号跨作品共享信息 | 有限且集中；KuaiRec跨窗口不稳定，KuaiRand账号区间跨零 |
| 新增目录作品与库存的预测信息 | 见新作品补充；目录记录不同于完整生产史，预测系数不同于结构回报 |
| 创作者能力theta能否跟人跨账号转移 | 未识别；A/B仍是同一个真实账号上的不同作品 |
| 账号资本H不可转移与真正冷启动 | 未识别；没有注册日期、已知owner迁移或随机历史保留/重置 |
| AI成本下降导致生产或拆号 | 未识别；曝光数据来自2020/2022年历史记录，未观测AI使用或真实成本冲击 |
| 平台政策alpha | 未识别；拟合指数是受限预测形式，固定库存与自由账号截距完全混淆 |

不能把KuaiRand观看者`user_id/register_days`拼到创作者`author_id`上测账号年龄，也不能把Civitai改用户名或相近prompt当同owner拆号。[Mastodon官方迁移制度](https://docs.joinmastodon.org/user/moving/)甚至允许followers随迁移保留、旧posts却不迁移，说明资本可能部分可携带；“换号丢失全部优势”不是普遍制度事实。相关公开迁移论文没有本任务所需的可用impressions和AI成本随机化数据。本轮没有因不可识别而伪造结构参数。

## 五、修订后的博弈问题

建议课程项目的问题表述为：**稀缺曝光下，AI降本、数量回报压缩、新旧账号权重和最低内容要求，如何共同改变生产与身份竞争？**

平台先承诺数量指数alpha、验证政策（通过tau体现）和账号权重规则。经济意义上的创作者选择当前轮内容总量n、账号数k，以及内容放在哪个账号。每人一个旧号，新号权重为旧号的r倍；持续创作者类型theta可随其内容转移。固定质量、固定参与的一期收益为

\[
S_i=\theta_i\left[x_{iH}^{\alpha}+r\sum_{a=1}^{k_i-1}x_{ia}^{\alpha}\right],\qquad
u_i=R\frac{S_i}{S_i+S_j}-c_i\sum_a x_{ia}-\tau(k_i-1).
\]

本轮只核验平台给定规则下的创作者子博弈，没有估计平台偏好或求完整Stackelberg政策最优。平台可沿用V4的有限目标：最小化验证资源成本kappa·v²/2，约束为产量目标和单号行为，tau=tau_0+v；整数均衡多重或不存在时，还需要另外明确均衡选择，不能直接套连续政策解。

这里的n是本轮新生产；实证中的入选库存Q、目录发布流F与n不等同。theta、r、c和tau未被预测实验校准。r=1保留为无冷启动优势的基准，r<1是可检验机制情景，不能由历史份额胜出直接选定。

在R、c_i、theta_i、tau>0、0<alpha<1、0<r≤1，且允许任意小内容强度及连续账号数时，令eta=r^(1/(1−alpha))、b_i=theta_i c_i^(−alpha)，有

\[
p_i=\frac{b_i}{b_1+b_2},\quad M=R p_i(1-p_i),\quad
n_i^*=\frac{\alpha M}{c_i},\quad
k_i^*=1+\max\left\{0,\frac{(1-\alpha)M}{\tau}-\frac1\eta\right\}.
\]

alpha=1单独处理为k=1，不代入无定义的eta。双方同比降成本提高生产但不改变份额和账号数；单方降成本若帮助落后者接近各半份额，会提高拆号激励，若扩大领先则会减弱；账号数只在内部区或跨越门槛时改变，单号角点可能保持不变。以上是共同r、共同身份成本、固定类型的连续条件命题，不是实测AI规律。

## 六、最低内容与整数结果改变了什么

要求每个账号至少一件作品时，仅有n≥k还不足。固定整数k≥2、连续n，0<alpha<1时，所有新号满足内点分配至少一件，需要更强条件

\[
n\ge k-1+1/\eta.
\]

k=1仅需n≥1，单位类型积分为n^alpha。k≥2而上述条件不足时，新号每个恰放一件、旧号承载余量，未乘theta_i的积分为(n−k+1)^alpha+r(k−1)；超过时才恢复V4的加权凹聚合，实际S_i还需乘theta_i。作品也整数时，本轮枚举旧号件数，并把新号整数内容平衡分配，完整检查联合偏离。

176个运行前固定参数条件覆盖全部潜在最佳反应整数动作：因为(n,k)=(1,1)收益>−c，而n>R/c+1的动作收益<−c，可据此排除未枚举动作。175个条件有纯均衡，1个没有；19个条件连续预测拆号但整数模型包含单号均衡。56个完全可实施的连续候选均被整数均衡集合包含，这是可行集合包含论证支持的特殊情形。

预定网格中发现了严格反向案例：R=12、alpha=.5、r=1、tau=.5、theta=(2,1)、c_2=.5，第一位成本从2降至1，连续账号数从3降至约2.912；但连续候选违反其最低内容要求。实际整数严格均衡从((1,1),(3,3))变成((2,2),(3,3))。所以最低内容绑定时，不能套用“份额更不均衡使双方账号数下降”的内点结论。

另有给定参数条件case148没有纯均衡，全动作最小最大偏离收益约0.009725，远超容差，不能用近似稳定点冒充均衡。没有计算混合均衡，也未据此宣布全模型无纯均衡。96个相邻新号权重比较未见降权后更多拆号，仅为网格证据；模型固定参与，未评估新创作者进入损失或公平。

完整积分、KKT、反例与独立核验见[V5_THEORY_VALIDATION.md](V5_THEORY_VALIDATION.md)。这是一套已有contest/身份操纵框架下的应用问题与条件分析，没有以“加入历史”宣称新的基础博弈理论。

## 七、对原猜测的修订

应保留的是：统一数量函数不足以描述曝光，作品及创作者之间的持续异质性需要进入基准；身份与生产是两类不同投入，平台治理不能只考虑其一。

应收窄的是：历史基线胜出并不建立强账号资本。跨作品与新作品预测提供的是关联信息，无法判断优势是否能跟人跨账号转移；冷启动权重只能作情景分析。

应修正的是：连续拆号门槛和AI单方降本比较静态不能跳过最低内容约束与整数均衡，后者可以出现方向不同的严格反例及纯均衡不存在。

动态扩展仍须区分新生产、存量作品、资本折旧、一次性开设和持续维护成本。现有数据不识别这些状态转移，因此本轮没有把一期解冒充动态Markov完美均衡。

## 八、复现、完整性与局限

全部原始数据、逐作品数组和账号标识留HKUST3独立v5目录；本地仅源码、必要文档和小型汇总。各执行回执记录真实退出码，协议与代码SHA可查。主要数值从保存贡献重构，整数分配另以全composition及单边偏离复核；检查的范围不超出其数据和参数条件。

旧作品样本经过平台与数据集选择，KuaiRec还按未来行存在性构成平衡池。曝光事件存在重复观看者和时间相关，条件bootstrap不覆盖所有依赖与重拟合不确定性。数量、反馈、历史及样本选择都可能内生；预测改善不识别结构收益、真实owner、平台福利或AI成本效应。负面、集中和无纯均衡结果均完整保留。
