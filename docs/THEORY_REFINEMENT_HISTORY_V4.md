# 从历史曝光预测优势到账号资本博弈

记录日期：2026-11-05（北京时间）。本轮只解释V3结果并推导候选模型，没有新增实证估计、数据采集或动态均衡数值实验。

## Target

解释“训练期历史曝光份额比数量模型更能预测未来曝光”的含义，提出与原数量—身份博弈衔接的可解扩展：**持续的创作者差异、不可转移的账号资本和新账号冷启动，如何改变数量治理与拆号激励？**

即时目标是一个固定历史状态下的一期条件命题。动态库存、历史资本积累及进入退出作为后续模型，不把它们写成已经求解的均衡。没有据此宣称理论原创优先权。

## Status

**COHERENT AFTER REFRAMING / EXTRA ASSUMPTION**。

原“所有账号同等起点、内容等分”的模型保留为特例。新旧账号具有不同权重、且这种差异不能完全随创作者转移，是新增的可检验假设，尚未由V3数据识别。

## Invariant Object

创作者从稀缺曝光池获得的预期收益，减去生产和额外身份成本：

\[
u_i=R\frac{S_i}{S_i+S_j}-c n_i-\tau(k_i-1).
\]

区分三个对象：平台曝光、创作者实际收入和内容质量。这里只假定曝光以固定比例转换成效用；没有估计真实货币收入。

## Assumptions

1. 一个平台先承诺规则，两位经济意义上的创作者随后同时选择总内容强度、账号数及账号间内容分配。平台不需要知道跨账号owner，只逐账号打分；模型分析者按owner合并收益。
2. 两位创作者各拥有一个老账号，可增加新账号。单期分析固定所有历史状态，没有把当期所得曝光用于当期评分。
3. \(n_i>0\)和账号内容\(x_{ia}\ge0\)是连续强度；\(k_i\ge1\)是连续松弛。没有每账号至少一件作品的要求。不能把结果直接四舍五入为真实整数账号均衡。
4. 对称可解切片中，两人生产成本c、原有账号权重w_H、新账号权重w_0及固定质量相同；\(R,c,\tau,w_H,w_0>0\)，\(w_H\ge w_0\)，\(0<\alpha<1\)。
5. w_H与w_0描述附着在账号上的不可完全转移优势，例如账号受众、信誉或平台已学到的匹配。它们不是单凭历史曝光回归即可识别的因果参数。
6. 本轮n指本轮新内容强度，cn是相应生产成本。现有V3的n却是固定候选池库存，二者不可直接等同。这一期模型没有继续推荐老作品的库存动态。
7. 平台阶段先固定新旧权重比；分析给定产量目标下的最低验证成本，不声称已求出平台利润或社会福利最优。主动提高老号权重的公平与进入代价另列为开放问题。

## Notation

| 符号 | 定义 |
|---|---|
| y_at | 数据中账号a在日期t记录到的曝光数 |
| h_a | 仅用训练期曝光计算的平滑历史份额 |
| theta_i | 创作者层面的持续类型，如稳定内容能力；可随创作者转移到其新账号 |
| w(h_a) | 账号层面的权重；是否真正由历史造成仍待识别 |
| w_H、w_0 | 一期切片中老账号、新账号权重 |
| r=w_0/w_H | 新旧账号权重比，属于假设参数，未从V3估计 |
| eta=r^(1/(1-alpha)) | 一个新账号相对老账号的有效评分贡献系数 |
| n_i、x_ia | 当前轮总内容强度及其账号分配，总和为n_i |
| k_i | 包含原有账号在内的连续账号数松弛 |
| alpha | 单账号内容强度的评分弹性 |
| R、c、tau | 固定收益池、单位内容成本、每个额外账号的单期成本 |

## Derivation Strategy

先解释预测比较的统计对象，再区分可转移创作者类型与不可转移账号资本；固定历史状态，先优化账号间内容分配，再求创作者子博弈。最后说明一期命题与动态模型、现有数据各自的边界。

## Derivation Map

1. V3历史基线是高维账号份额估计，胜出表明存在持续可预测信息；不识别历史反馈。
2. 持续信息可能属于创作者、账号或旧作品；只有不可转移的账号优势直接产生冷启动损失。
3. 用加权凹积分定义策略收益，推导不均匀内容分配。
4. 对称、连续切片给出生产量与拆号门槛；原模型是r=1的特例。
5. 给定新旧权重比，推导平台满足产量目标和单账号均衡所需的最低验证成本。
6. 动态扩展必须区分新生产、存量作品、账号历史和一次性/持续身份成本；不直接套用一期结论。

## Main Derivation

### Step 1：V3结果的准确统计含义【定义与解释】

两个脚本的历史基线都是训练期平滑份额：

\[
h_a=\frac{\sum_{t\in\mathrm{train}}y_{at}+0.5}
{\sum_b\sum_{t\in\mathrm{train}}y_{bt}+0.5A},
\]

随后冻结，预测全部测试日期；不是在测试期滚动更新，也没有直接读取测试曝光来拟合。测试日曝光总量只用于评价加权，不是模型预测的总量。

历史基线隐含A−1个账号份额自由度：KuaiRand为6,509，KuaiRec为866；数量模型只有一个alpha，反馈/年龄模型最多三个公共参数。代码中的`parameters=[]`仅表示没有再通过优化器拟合一个低维参数向量，不能解释为历史模型零参数。

因此，结果支持“账号特异的信息可以持续到短期留出期，而少量共同参数没有捕获它”。不能将预测损失差解释为两个因素的因果重要性排序。高维模型在留出期仍胜出有预测意义；高维本身也不等于测试泄漏。

还有一个重要限制：KuaiRand约86.96%、KuaiRec约94.69%的入选账号都只有一个入选视频；训练、测试又使用同一批老作品。数量模型会给许多账号相同的数量分数，历史份额却能区分这些账号。历史基线可能主要记录旧作品的持久吸引力。

### Step 2：先区分三种解释【机制假说，不是实测结论】

| 解释 | 历史为什么预测得准 | 对拆号的不同含义 |
|---|---|---|
| 创作者持续类型 | 能力、题材、受众匹配长期不同 | 若优势能随人转移，改账号不一定损失优势 |
| 账号资本或真实反馈 | 账号粉丝、信誉、匹配记录，或过去曝光改变未来机会 | 新账号不能继承时，拆号有冷启动损失 |
| 旧作品持久吸引力 | 同一批视频在相邻时间窗继续受欢迎 | 主要需要作品状态模型；未必是账号声誉 |

“过去结果改变未来机会”与“原本不同的人持续得到不同结果”是不同机制。区分状态依赖与未观测异质性是经典识别问题，见[Heckman（1981）原章](https://eml.berkeley.edu/discrete/ch3.pdf)。这里将该原则应用到创作者数据，没有声称该原章研究了本项目的拆号行为。

### Step 3：改写账号评分【候选结构假设】

一般候选可写为

\[
S_i=\theta_i\sum_{a\in\mathcal A_i}w(h_{ia})x_{ia}^{\alpha},
\qquad p_i=\frac{S_i}{\sum_j S_j}.
\]

theta_i是可转移的创作者类型，h_ia是账号状态。函数w可以先作为单调的候选机制，而不直接把历史回归系数命名为算法权重。

以下只解theta_i相同、一个老号权重w_H、每个新号权重w_0的切片：

\[
S_i=w_Hx_{iH}^{\alpha}+w_0\sum_{a=1}^{k_i-1}x_{ia}^{\alpha},
\qquad x_{iH}+\sum_a x_{ia}=n_i.
\]

当w_H=w_0时退化为原模型。两者不同时，原来的等分内容分配不再最优。

### Step 4：账号间的最优分配【条件命题】

给定整数k和连续n，拉格朗日条件是

\[
\alpha w_H x_H^{\alpha-1}=\alpha w_0 x_a^{\alpha-1}.
\]

定义\(\eta=(w_0/w_H)^{1/(1-\alpha)}\in(0,1]\)，可得

\[
\boxed{x_H=\frac{n}{1+\eta(k-1)},\qquad
x_a=\frac{\eta n}{1+\eta(k-1)}}.
\]

每个新账号获得的内容强度是老账号的eta倍。代回积分得到恒等式：

\[
\boxed{S(n,k)=w_Hn^\alpha[1+\eta(k-1)]^{1-\alpha}.}
\]

该表达式先对整数k来自实际分配，再延伸到连续k用于分析松弛均衡。r=1时eta=1，正好恢复\(k^{1-\alpha}n^\alpha\)；新旧账号不能等价时，原拆分倍率需要重推。

### Step 5：固定历史状态的对称均衡【条件命题】

收益为\(R S_i/(S_i+S_j)-cn_i-\tau(k_i-1)\)。积分对(n,k)联合凹：它是n与正仿射量1+eta(k−1)的Cobb–Douglas函数；竞赛收益对积分递增且凹。因此可行的一阶/KKT条件足以验证最优反应。

令\(M_i=R p_i(1-p_i)\)。生产的一阶条件为

\[
cn_i=\alpha M_i.
\]

拆号内点满足

\[
\tau=\frac{(1-\alpha)\eta M_i}{1+\eta(k_i-1)}.
\]

两位创作者对称时p_i=1/2、M_i=R/4，得到

\[
\boxed{n^*=\frac{R\alpha}{4c}},
\qquad
\boxed{k^*=1+\max\left\{0,\frac{R(1-\alpha)}{4\tau}-\frac1\eta\right\}}.
\]

特别地，单账号均衡的条件是

\[
\boxed{\tau\ge\frac{R(1-\alpha)\eta}{4}}.
\]

eta=1恢复原条件；eta越小，新账号越难继承优势，拆号越不划算。这个门槛是连续账号松弛模型的边际门槛，不是一般整数账号模型的精确阈值。

例子仅作模型演示：R=12、alpha=0.5、c=0.5、tau=0.5。若新旧账号等权，eta=1，松弛均衡为(n,k)=(3,3)；若老账号权重为新账号两倍，则eta=0.25，松弛均衡为(3,1)。这些数字没有从平台数据估计；不能把这个整数形状的例子当作整数模型的一般证明。

降低c仍提高n，而在这一松弛切片中不直接改变k。因此，本扩展并没有得到“AI成本越低，账号必然越多”。AI冲击首先进入生产成本，是否改变账号选择还取决于约束、身份成本、质量与状态演化。

### Step 5a：保留持续类型与不同AI成本【异质条件命题】

为避免承认数据中的异质性后又完全依赖对称假设，可保留theta_i与c_i不同，仍要求新旧权重w_H、w_0及身份成本tau相同。积分改为theta_i乘上Step 4的表达式。

两人的\(M_i=R p_i(1-p_i)\)仍相同，记为M。生产条件给出\(n_i=\alpha M/c_i\)；共同的账号KKT条件给出相同k。于是令

\[
b_i=\theta_i c_i^{-\alpha},\qquad
p_i^*=\frac{b_i}{b_1+b_2},\qquad
M=R\frac{b_1b_2}{(b_1+b_2)^2},
\]

可得这一连续模型的均衡：

\[
\boxed{n_i^*=\frac{\alpha M}{c_i}},\qquad
\boxed{k_i^*=1+\max\left\{0,\frac{(1-\alpha)M}{\tau}-\frac1\eta\right\}}.
\]

theta、c相同时恢复M=R/4。只有theta不同且c相同时，\(M=R\theta_1\theta_2/(\theta_1+\theta_2)^2\)。因此异质模型不能始终把R/4当精确系数；它是M的上界。

这个扩展提供更具体的AI条件预测：单方降低c_1会提高b_1。如果原本较弱的创作者因此接近双方各半的份额，M增加，连续账号数可能增加；如果已经领先者进一步扩大领先，M下降，账号数可能下降。跨过各半份额时方向也随之改变；停留在k=1边界时，变化可能不影响账号数。

对应的导数为\(dM/d\log c_1=-\alpha M(1-2p_1)\)。双方成本同比下降时，份额与M不变，所以账号数不变；双方生产强度按成本下降比例增加。

这说明身份竞争取决于竞争是否势均力敌，而不只是AI是否便宜。它是固定质量、共同账号优势和共同身份成本下的理论比较静态，尚未获得AI采用或owner数据验证。不能把它直接外推为实际平台的普遍规律。

### Step 6：平台的条件性设计问题【条件命题】

这一段回到两位创作者theta、c相同的切片。固定r=w_0/w_H，不允许平台无代价地抹除新创作者机会。平台选择alpha与验证增量v，使tau=tau_0+v；要求每人产量不超过N且维持单账号均衡，并最小化\(\kappa v^2/2\)。仍使用连续强度与账号松弛。

记\(b=4cN/R\)。若b≥1，可取alpha=1，拆号无积分收益，所需额外身份成本下界为0。若0<b<1，产量约束要求alpha≤b，而单号条件要求

\[
\tau\ge T(\alpha)=\frac R4(1-\alpha)r^{1/(1-\alpha)}.
\]

令z=1−alpha，导数为

\[
\frac{d}{dz}\left[z\exp\left(\frac{\log r}{z}\right)\right]
=\exp\left(\frac{\log r}{z}\right)
\left(1-\frac{\log r}{z}\right)>0.
\]

所以允许的最大alpha=b最节省验证，得到

\[
\tau_{\rm required}=
\begin{cases}
\frac R4(1-b)r^{1/(1-b)},&0<b<1,\\
0,&b\ge1,
\end{cases}
\qquad
v_{\min}=\max\{0,\tau_{\rm required}-\tau_0\}.
\]

r=1且b<1时，恢复原来的\(cN+\tau\ge R/4\)。账号资本降低所需验证成本，是这个固定r模型内的比较静态；它不构成扶持老账号的无条件政策建议。若允许平台选择r，还须加入新创作者进入、冷启动曝光或公平约束，否则模型会把锁定老号当成几乎免费的解决办法。

### Step 7：动态扩展应改哪些对象【尚未求解的模型设计】

若历史优势确实属于可积累的账号状态，仅加一个滞后解释变量还不够。至少应区分：

- \(n_{at}\)：本期新生产，承担本期生产成本；
- \(Q_{at}\)：仍可推荐的作品库存，可用\(Q_{a,t+1}=(1-d)Q_{at}+n_{at}\)作初步近似；
- \(H_{at}\)：账号资本，候选更新为\(H_{a,t+1}=(1-\rho)H_{at}+\rho p_{at}\)；
- 创建账号的一次性成本与持续维护成本，以及关号时资本是否丢失。

这里Q的单一折旧率近似与H的曝光份额更新都是待检验假设，不是从数据中读出的定律。动态创作者最大化贴现的曝光收益，减去新生产、开设和维护账号成本，并考虑未来资本价值。

这样会出现真实的跨期取舍：新号增加评分入口，却损失已有匹配或受众；AI降低当期供给成本，却未必消除新号获得信任所需的时间。是否会形成低质量套利、老号集中或新作者进入障碍，必须在完整状态转移与收益下求解，不能直接把一期k*当动态均衡。

作为另一种最小建模路径，也可以设\(p_i=(1-\lambda)h_i+\lambda S_i/(S_i+S_j)\)。固定历史时它只把原单期竞赛奖金替换为lambda R，具有解释作用，但本身没有构成新的博弈机制。该加法模型与上述乘法权重模型是不同候选，不能把各自公式拼接使用。

## Remarks and Interpretation

### 接下来怎样区分三种机制

1. **先检验跨作品可迁移性。** 在849个KuaiRand多作品账号中，把账号内作品分成A/B；只用A的普通训练曝光提取账号信息，预测B的未来普通曝光。B可以使用事先允许的随机训练反馈代理，但不用B自己的普通训练曝光记忆。这样能检验信息是否跨作品共享，仍不能区分创作者类型与账号资本。
2. **再检验历史保存多久。** 事先固定历史窗口和测试间隔，在多个预测起点比较冻结、衰减与滚动历史；所有输入只使用预测时点之前的信息。稳定异质性与短期状态可能表现不同，但预测衰减也不单独识别因果。
3. **比较数量的新增预测价值。** 在共同信息集、共同样本与正则化规则下，比较已有历史/需求/年龄的模型，再增加可观测新增供给和库存变量。当前固定池中的n不随日期变化，不能用账号固定效应估计其独立数量弹性：\(b_a+(\alpha-1)\log n_a\)中的alpha可完全被b_a吸收。
4. **单独评估冷启动。** 区分老账号老作品、老账号新作品、新账号新作品。现有固定池评估主要覆盖第一类，不等于已经验证后两类。新作者和新发布队列需要相应可观测数据，不把缺失日期补零。
5. **因果检验另立设计。** 要判定“历史曝光本身改变未来机会”，优先随机探索曝光或有可信识别假设的外生规则变化；仅在回归中加入历史不能解决这一点。要检验拆号，还需要已知owner及真实成本与身份选择。

上述方案本轮尚未执行。滚动起点评估的预测原则可参见[Tashman（2000）](https://doi.org/10.1016/S0169-2070(00)00065-0)；它改善预测比较，不自动建立因果识别。

## Boundaries and Non-Claims

- 本轮数据支持持续可预测信息，没有证明平台直接按历史分配流量，也没有证明新号存在特定程度的冷启动惩罚。
- 创作者持续类型与账号状态分别建模；不可转移账号优势是新假设，不是由历史胜出必然推出的结论。
- 最优分配和闭式均衡只适用于无单账号最低作品约束的连续强度切片；当x_a≥1或n、k均为整数时，需要重新求联合偏离，不能照搬V2约束公式。
- 新增供给与可推荐库存分别计量，不能拿库存回归的alpha直接校准新生产博弈。
- theta、r、alpha政策强度、真实c和tau均没有被V3识别。没有把预测参数称为结构参数。
- 尚未求解动态Markov完美均衡，也未分析创作者进入退出、质量努力或平台完整福利目标。
- [Yao等（2024）](https://arxiv.org/abs/2404.18319)已经研究推荐机制如何影响竞争创作者策略与用户福利；动态反馈、创作者竞争与身份操纵各有既有文献。本项目应定位为特定平台问题的应用博弈与条件分析，不能以“加了历史”宣称首创。
- 一期资本模型还可用有效身份量z=1+eta(k−1)重参数化为原contest，并将每单位有效身份成本写成tau/eta。因此这里提高了机制解释与可检验性，没有产生一套新的基础博弈理论。

## Open Risks

1. 新旧权重差究竟是账号资本、质量差异还是旧作品记忆，现有数据不能区分。
2. 一期模型允许任意小的新号内容强度；离散作品与账号成本可能显著改变门槛。
3. 平台压缩数量收益与提高老号优势都可能抑制新进入者，缺进入/公平约束会产生失真的政策建议。
4. 暴露历史是平台与创作者共同产生的结果；把它当外生权重是一期切片的条件化处理，不是完整因果模型。
5. 只加丰富账号效应会提高短期预测，却可能使数量机制不可识别；预测与结构识别需要分别评价。
