# V8 给主笔的理论编辑建议

## 先说清楚这项研究实际在做什么

建议主问题改写为：**怎样区分旧作品持续获得的曝光、账号共享信息与新生产，避免把旧作流量误当成继续创作的回报？**

我们用公开曝光记录检验“哪些历史信息能预测未来”，再把这些信息层次放进一个创作者竞争模型。研究没有估计AI使成本降低了多少，也没有找到同一真人的多账号，更没有观察到平台如何选择最优政策。它实际推进的是：把旧作获得流量与新生产带来的回报分开；发现共享账号信息在新作与旧作上的价值不同；据此重新求解一个允许旧作品持续产生曝光的两期博弈。

不要将全文组织成“先提出拆号理论，再寻找支持”。证据已经使最初的拆号叙事收窄，这是研究结论的一部分。

## 正文最少保留哪个game

正文保留**平台规则给定、两位创作者跨两期选择生产量的竞争**即可。平台先承诺推荐规则；实际求解的是创作者之间的子博弈，不是平台与创作者共同选择政策的完整均衡。观众提供有限注意力，不另设战略玩家。

用五步解释运作过程：

1. 期初，每位创作者已有一些仍能推荐的旧作品，也有账号层面的受众或匹配信息。
2. 两人同时决定今天生产多少新内容；旧作和新作一起竞争曝光。
3. 获得的曝光有价值，制作新作要付成本。
4. 一部分作品留到明天，账号信息也可能积累；这种转移在模型里是明确假设，尚不是数据识别的定律。
5. 明天两人再根据新状态行动。真正的前瞻解会在今天考虑这些后果，而不是明天到了才重新算一次短视最优。

最小收益写成一句话：**本期曝光效用减去本期制作成本**；前瞻目标是两期净收益的贴现和。需要写公式时，仅保留 \(R p_i-c_i x_i\)。

新增账号放在一个短框中：如果允许开新号，策略再增加“是否开、内容放哪”，成本增加 \(F o_i+\mu(k_i-1)\)。收益仍是同一个经济主体名下全部账号的曝光效用之和。这是扩展情景，不必让开户门槛成为正文主线。

## 给读者的术语表：每个符号只负责一件事

| 符号 | 读者应记住的含义 | 不要混成什么 |
|---|---|---|
| \(B\) | 仍可参与推荐的旧作品有效存量 | 不是本轮新生产，也不是直接观测到的曝光次数 |
| \(H\) | 附着于账号的积累，如匹配信息或受众关系 | 不是“历史曝光回归显著”就证明的因果资本 |
| \(\theta\) | 随创作者持续存在、可能跟人转移的能力或题材匹配 | 与不能完全随人转移的账号优势不同 |
| \(x\) | 本期实际选择的新生产 | 不是观察目录里共有多少作品 |
| \(\alpha\) | 推荐积分如何随内容量变化；1为线性，小于1为边际递减 | 预测模型选出的指数不等于平台真实程序参数 |
| \(F\) | 开一个新号的一次性成本 | 不能每期重复收一次开户费 |
| \(\mu\) | 已存在的额外账号每期维护成本 | 与开户费、制作成本分开 |
| \(c\)、\(R\)、\(p\) | 制作成本、曝光效用池、曝光份额 | 曝光份额不等于现金收入或内容质量 |

正文不必完整展开评分函数。可以先说：“旧作与新作形成可推荐内容，再由账号条件影响竞争积分。”如确需一个表达式，使用 \(S_i=\theta_i w(H_i)(B_i+x_i)^\alpha\)，并说明有限曝光按竞争积分分配。

实证使用的作品记忆、账号残差比和目录权重，只是对应这些概念的预测代理。它们与理论评分可在形式上对应，**不代表已经测出了真实B、不可转移H、成本或状态转移率**。同账号跨作品的信息，也可能来自\(\theta\)，不能据此排除持续能力。

## 正文值得留下的四项结论

**第一，旧作品流量不是新增创作回报。** 数据中的自身作品记忆很有预测力；模型也允许旧作仍获曝光、创作者本期却不更新。两者方向相容，但不能说模型的零生产行为已被实证验证。

**第二，账号共享信息对新作品确实有用，不能一概否定。** 老作控制自身记忆后，额外共享信息很弱；没有自身历史的新作可以利用同账号其他作品的信息。这个结果支持在预测与建模中区分作品状态和共享信息，尚不能证明共享信息是不可转移资本。

**第三，前瞻生产与逐期短视是不同的问题。** 两期求解把所有当期偏离导致的后续均衡计入回报，确实可以改变今天的生产选择；这不依赖一定出现拆号。另做的24个线性评分情景中，所选路径均未开号，但前瞻首期行动仍区别于myopic对照。不要把这24个模型情景与实证的32次指数选择混为一个样本。

**第四，拆号目前是条件性政策机制。** 四个预测族在八个校准单元均选择\(\alpha=1\)。这不是证明真实平台永远线性，却意味着本轮数据没有支持“现实推荐按凹数量奖励，从而诱发拆号”的关键前提。在线性、旧号权重不低于新号、正身份成本的一期切片里，多开入口本身没有评分优势。正文应据此收窄经验主张，不能为了保持最初选题，把凹规则写成已知事实。

## 只保留一个真正说明前瞻的例子

建议用“今天的选择会留下明天的作品与账号状态”解释已核验的两期特例：**只看当期时本期生产为0.5，考虑后续状态时约为1.83。** 这两个数只属于给定参数的模型演示，不是平台估计，也不是所有情景都会增加生产。关键是选择为何不同，而不是分数形式漂亮。

正文无需列出11/6、59/24、13/24、177/32或全部参数；完整条件、后续最优反应及离轨补齐留附录。若篇幅更紧，连数字也可删，只用两条有明确“模型示例”标记的路径图。不能只说“未来收益更高所以多生产”，必须保留“今天的行动改变明天状态，且对手也会重新行动”这一博弈含义。

## 应移出正文的内容

- clamp分配、perspective凹性、\(G_1-G_0\)门槛证明，以及生产搜索界。
- 176点整数网格、72个两期条件、终期子博弈计数和逐项数值精度。正文一句“已完整逆推并检查单边偏离”，附录提供验收即可。
- 为说明存在性而选择的高开户费16、B=100等特殊参数；它们是数学检查，不是研究动机或现实发现。
- 所有AI降本方向的分区公式。正文只说“方向取决于已有状态、竞争与未来价值；本轮未观察外生成本变化”。
- 从新号降权直接推导治理建议。模型没有计入真实新作者进入、误伤或平台完整福利。

## 写作中必须守住的断点

1. **能预测曝光 → 不能直接推出创作者行为或因果机制。** 成本和实际选择没有被这些曝光回归识别。
2. **同账号共享信息 → 不能直接推出跨账号不可转移。** 当前没有可信owner链接或迁移处理。
3. **评分形式对应 → 不能直接推出B/H转移已验证。** 当前状态转移预测并未胜过简单延续基准。
4. **给定平台规则下的均衡 → 不是平台最优政策。** 平台规则在当前博弈外固定。
5. **有限两期解 → 不是一般无限期或无界动作结论。** 多重均衡与选取规则也应留在附录说明。

建议全文最后收束为：**我们在预测与建模中区分了旧作、共享信息与新生产，并据此建立和求解了更合适的生产竞争模型。拆号是这个模型在特定规则下的扩展问题，仍需要新的身份、成本和制度证据；本轮没有证明AI使创作者大量拆号。**
