# V7 独立小源补充：公开 opt-in YouTube impressions

2026-11-05。另行冻结后才分析，不修改 KuaiRec 协议和主结果。来源为 OpenChannelStats manifest 的 7 个公开自愿披露频道入口；1 个空入口保留为覆盖事实，不伪装有效作者。真实日报字段含 impressions，但这是自愿小样本，不是 YouTube 完整/随机频道池或共同竞争预算 R。

只使用公开 CSV `videos.csv` 的静态 video_id/published_at，及 `video_daily.csv` 的 date/days_since_publish/impressions；不把 lifetime、day1、peak 或末日汇总作历史输入。channel_daily 仅用于新发布日的描述性关联。原始文件已由采集代理逐个源 SHA 验收；本脚本再次记录输入哈希。缺失 impressions/日期行不补零；负的发布年龄、早于发布或晚于本行 recorded_through 的行排除并计数。CSV 未导出 pre_publish_stub 标志，日期/年龄过滤不能保证消除所有来源收录选择。

每频道独立以最后有效 impressions 日为测试末日，向前划 14 个训练自然日、7 个校准自然日、7 个测试自然日，实际缺行保持缺失。至少 7 个训练观测日期，校准及测试各至少 2 个多视频观测日期，否则只作覆盖描述，不拟合。各频道时间窗可以不同；不把共同日历或完整 28 日覆盖强加给数据。

同日同频道实际有非缺 impressions 的视频为共同条件候选池。比较：均匀视频；训练年龄分组均值（10 个 video-day 先验）；年龄基准乘目标视频过去 impressions/年龄基准期望的收缩记忆（固定 7 日半衰期、7 个 video-day 先验，γ仅校准选{0,.5,1}）；前一自然日 impressions+1（前日无记录则回年龄基准）。状态只用 t 之前记录，测试期逐日更新，不是多步冻结预测。首日新作没有自身过去输入。

报告每频道及逐频道条件池合并的曝光加权交叉熵、年龄×记忆−年龄差；合并只汇总评分，不假设频道间共同市场分母。日期配对重采样 1,000 次，有限频道和时间相关限制区间；参数不解释为结构库存折旧、平台规则或账号资本。

另在测试日描述“发布新视频日/无新视频日”的过去已上传作品曝光（总量、每实际观察旧作均值、覆盖数和日期数）；发布依据 channel_daily，旧作依静态发布日期<当天。缺失曝光不补零、无匹配频道日不擅自叫零发布。可能受内容选择、日历需求、频道趋势与覆盖变化影响，不是发布造成蚕食或流量增益的因果估计。

单频道同日公共账号权重在份额归一化中约掉，即使扩至几个自愿频道，也没有完整同场景预算，故不估 β_H、冷启动 r 或 θ/H。该补充只拓展真实 impressions 下作品持续性的预测/描述证据，不能充当理论状态转移或 AI 成本验证。

独立远端 `v7/openchannelstats_empirical/`；只 CPU 单线程。原始/逐行数据留远端，本地仅源码和小型聚合；记录真实退出、至少两个实测阶段与最终验收。
