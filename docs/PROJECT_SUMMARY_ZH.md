# AI 内容平台与创作者博弈 课程讲解

我们研究的问题是：AI让创作更便宜后，平台想降低“同一账号多发作品”的奖励，创作者会减少发布，还是把作品分散到更多账号？

## 一句话讲清博弈

平台先定推荐规则，两位创作者随后同时选择产量和账号数。观众的注意力总量固定，因此创作者争夺的是有限的曝光。平台和创作者都在预判对方的反应，这构成一个Stackelberg博弈；给定规则后的创作者选择构成Nash子博弈。

## 模型怎样运作

每个账号有x单位内容，推荐积分是x的alpha次方。alpha=1表示按数量同比增加积分，alpha<1表示多发的边际回报下降。创作者把n单位内容均分到k个账号后，总积分为k^(1-alpha)n^alpha。其收益是总曝光R乘以自己的积分份额，再减去生产成本cn和额外账号成本tau(k-1)。

同样的作品分成更多账号，在alpha<1时会取得更高积分。这个现象在既有Sybil和false-name文献中已有研究；课程项目的新问题是如何把它与AI成本变化、平台数量目标和最低内容约束放在同一个可求解模型中。

## 最重要的理论结果

连续基准的均衡是n*=R alpha/(4c)，k*=max{1,R(1-alpha)/(4tau)}。平台想让产量不超过N，同时维持单账号均衡，需要cN+tau>=R/4。

这个条件的意思是：生产和额外身份都很便宜时，仅靠压低同账号数量奖励，未必能同时控制供给和拆号。提高账号验证成本可以改变条件，但模型没有计算真实新创作者受到的进入负担。

补上“每个账号至少有一单位内容”的约束n>=k>=1后，结果更接近实际：高成本时每人一件一号；中间成本区间中，每加一个账号都必须多生产内容，AI降低成本会同时增加产量和账号数；非常低成本时，账号数量才进入平台区，而产量继续增长。

整数账号不能直接四舍五入。我们对最优产量和整数账号的联合偏离单独枚举，并推导了只需检查双账号偏离的单账号均衡阈值。仍应记住：扩展中的产量是连续变量。

## 数据确实做了什么

在HKUST3下载并校验了公开历史Civitai元数据。327,138源行去重后为325,599件作品，日期2022-11-09至2023-04-12。主要分析使用184,072件带SFW标记且有作者名的记录，涉及12,910个账号。

账号内记录数中位数为3，90分位为28。151,833条非空提示词中，同账号标准化后重复的超额记录占27.32%。它可能来自同一提示词换seed等正常创作，不表示作品低质、抄袭或账号属于同一个人。互动大多为零，因而没有拿点赞估计质量。

把同一作品池放到假设的推荐规则下，alpha由1降至0.5，前10%账号的份额由67.33%降至32.49%；对可以拆成两个非空账号的账号，单边拆分的中位毛份额增幅为41.41%。这展示了“份额更均衡”与“身份激励可被规避”之间的张力，不能当作Civitai真实算法的效果。

## 如何向老师展示

先提出“按账号压缩奖励会不会诱发拆号”的问题；然后解释三个玩家、先后顺序和收益；推导连续均衡与cN+tau的阈值；再用最低内容约束解释AI成本变化的分区；最后展示真实数据的分布与固定池回放，并说明历史快照不识别因果效应。
