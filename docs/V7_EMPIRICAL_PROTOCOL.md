# V7 实证协议：作品记忆、共享账号信息与可见供给

日期：2026-11-05。机器冻结时刻及哈希另存 `src/v7/empirical/protocol.json` 与审计，先于拟合运行。复用已探索的 KuaiRec 历史元数据，是探索性留出检验，不称独立预注册或平台因果实验。

## 数据与预测对象

输入 `v3/kuairec/item_daily_features.csv`，源 SHA256 `45943d63c44652b6403f3a4f78c7225e1afe7916bab17d9a674d7979245e085b`；本轮远端再次校验。使用全部源中实际出现的视频日，不加未来存活或未来正曝光筛选。候选池为**当天来源实际记录的作品**，是条件于被观察池的分配预测，不是完整 prospective 推荐池。缺失日不作真实零曝光；状态只累积已观察记录，因而本身也是覆盖不完整的观测代理。

四起点沿用索引 0、14、28、35，各训练 14 日、校准 7 日、测试 7 日；测试日不重叠。训练拟合共同年龄/时长基准，校准仅选择全局有限网格，测试仅评价。一日预测只使用日期 t 之前的记录；状态在校准和测试内按已经发生的前日记录更新，因此不是训练末冻结的七日远期预测。作品时长和上传日期为静态元数据。

## 公共账号状态与评分桥梁

用 `SHA256("v7-kuairec-disjoint|"+video_id)` 的首段整数奇偶分组 A/B，不依赖曝光或未来存活，不按作者平衡。A 源历史预测 B 目标作品，再反向复核；两方向是同数据交叉使用，不算独立复制。无源作品历史的账号保留并回共同先验。账号状态从**不相交源作品**构造，故同日同账号所有目标作品使用严格公共权重；不用目标作品参与其自己的账号历史。

训练期按固定年龄区间 [0,1,3,7,14,30,90,365] 与时长分组 [0,7,18,30,60] 秒估计每个视频日平均曝光，50 个 item-day 当量收缩到训练全局均值 μ，给出正的基准 e(v,t)。不存在分组回 μ。未使用目标当日曝光、点赞或播放反馈。

所有过去记录按固定 7 日半衰期衰减，ρ_obs=2^(−1/7)，不是拟合结构库存折旧。令 E_v(t)、D_v(t) 分别为目标作品过去实际曝光和过去基准期望曝光的衰减和，源组账号类似为 E_Aa、D_Aa。令 κ=7μ（7 个 item-day 当量）：

`m_v=(E_v+κ)/(D_v+κ)`，`h_a=(E_Aa+κ)/(D_Aa+κ)`。

无历史 m=h=1。它们是正的曝光残差记忆权重，不直接等于理论有效旧内容存量 B 或资本 H；h−1 也不被宣称为非负资本。

`z_v=(e(v,t)/μ)*m_v^γ`；`T_a=Σ目标候选作品 z_v`；

`score_v=h_a^β T_a^(α−1) z_v`；`p_v=score_v/Σscore`。

同账号聚合精确得到 `Σ_v score_v=h_a^β T_a^α`，与账号评分族存在形式桥梁。候选集、基准和既有信息截止对所有模型相同。α 是受限预测形式的数量指数，不是平台政策参数；m 的曝光单位不与理论生产量混称。

## 四个预定嵌套模型族

- 无状态：γ=β=0；α∈{.5,.75,1}，3 个候选。
- 仅作品：β=0；γ∈{0,.5,1}，α同上，9 个候选。
- 仅账号：γ=0；β∈{0,.5,1}，α同上，9 个候选。
- 双状态：γ、β各∈{0,.5,1}，α同上，27 个候选。

每个起点、方向各按校准视频级联合交叉熵选最小值，固定网格顺序解同值；不在测试选择，不追加更大网格。主比较为双状态−仅作品；另报告仅作品−无状态、仅账号−无状态、双状态−仅账号。较大校准容量可过拟合，嵌套不保证测试优胜。

Q 是预测日前已实际出现的目录视频数；F 是其中上传于过去 14 日的数量。仅作覆盖、供给分组及下面一步观测预测特征，不追加 Q/F 交叉熵网格搜索；它们不是完整产量、真实活跃库存或本期生产 n。

## 评价、集中与新作

报告同池视频与账号层面的曝光加权交叉熵、各起点方向、合并；源状态可用账号/作品与无源历史均保留。新作只取 `date==upload_dt` 实际行，首日为上传自然日非完整 24 小时；m=1，未使用其任何反馈。分别给新作联合贡献和在新作子池重新归一化的条件损失；并按固定训练窗已见/未见账号分组，未见不是新注册。

主差值给整日配对、四起点区块、固定预测账号聚类各 1,000 次重采样区间。两个方向先在同日/起点合并，避免把方向当独立数据。区间不含重拟合、选样、所有观看者/时间依赖或因果参数不确定性。

逐账号保存主差值贡献，汇总改善/变差账号数、曝光前十份额，并事后固定预测移除前 1/5/10 账号**评分贡献**，不重拟合或重新归一化；不是移除账号后的新市场。不能把改善集中于少数账号时写成普遍共享状态成立。

## 一步观测转移预测：避免构造恒等式充当验证

额外预测作品和账号的下一自然日 `log1p(实际观察曝光)`。只保留两天都实际有行且日期相邻的对，缺日不补零；下一日落在训练/校准/测试哪个窗，就分配到对应窗口。比较前日值直接延续、全局 AR(1)、AR(1) 加观测记忆/公共历史/Q/F/年龄基准的 ridge；惩罚仅从 {.1,1,10} 校准选择，截距不惩罚。输入都截止于前一日，下一日曝光仅为评价目标。

作品层扩展使用前日曝光、预测日之前的 m、来自另一作品组的 h、Q/F、年龄/时长基准；账号层使用前日账号总曝光、过去可见作品 m 的均值、全账号曝光残差权重和 Q/F。连续结果给 MSE/MAE 及相对 carry-forward，数量/状态变量不解释为结构转移。以源记录为条件的账号流量可因未观察作品变化；不预测完整平台总量。

这检验的是观测曝光在状态特征下的一步预测，不是对由定义决定的 m 更新做恒等式检验，更不叫验证 `B'=ρB+x`、`H'=δH+λp`，不识别真实 θ 与 H。
