# V5 KuaiRand：历史信息能跨作品迁移吗？

分析日期：2026-11-05（北京时间）。这是对V3结果的探索性机制诊断，不是平台随机实验；原V3结果已知，本轮没有将协议称作独立事前注册。

## 结论

同账号跨作品信号有小幅曝光加权预测增益，且比预定的身份错配负对照好；但账号聚类区间包含零，改善集中于少数高曝光账号。目标作品自身的历史远比跨作品信号有用。因此，本轮不足以支持一个普遍、强而不可转移的“账号资本”机制。

更准确的结果是：**固定旧作品池中，目标侧自身历史的预测信息很强，跨作品关联信息则有限、集中且不稳定。** 目标历史也可能更精确地测量共享创作者成分，不能把它的优势唯一归因于作品自身；两者都不能单独区分作品质量、创作者类型、受众或算法历史反馈。

## 协议与数据对象

使用[V3已校验的KuaiRand-Pure](https://kuairand.com/)元数据和日志，仅tab=1。固定上传早于2022-04-22的候选视频，按元数据选出849个多作品账号、1,922个作品；不按未来曝光删账号。随机日志只作长观看反馈代理，普通日志才是预测对象；未使用月度统计文件。

账号内平衡切半，固定10个seed，各做A→B和B→A；三组历史/校准/测试窗口分别为04-22..26/04-27..28/04-29..05-01、04-25..29/04-30..05-01/05-02..04、04-28..05-02/05-03..04/05-05..07。共60个分析单元，实际独特测试曝光25,559条。跨seed的255,590次评价是重复预测同一批事件，不能当新增样本。

来源A的普通历史只用于拟合共同数量、随机需求代理和年龄基准，并计算实际/预期曝光的收缩残差：

\[
f_a^A=(H_a^A+\kappa)/(E_a^A+\kappa),\qquad
\widehat p_{v,d}^B\propto b_{v,d}^B(f_a^A)^\delta.
\]

kappa∈{1,10,100,1000}、delta∈{0,.5,1}，仅以B普通校准曝光选择。**因此是B测试期留出，不是完全没有使用B普通曝光。** B自身历史基准允许读取B普通训练曝光，信息更丰富；不将它与A迁移当同信息集的公平竞赛。

完整方案见[V5_KUAIRAND_PROTOCOL.md](V5_KUAIRAND_PROTOCOL.md)。正式运行前，在功能smoke后明确追加了固定alpha=1的迁移对照，用于检验数量的增量预测价值；追加原因及探索性地位保留在协议中，没有省略初版smoke或替换不利结果。

## 主结果

每次曝光的账号层面交叉熵，单位nats，越低越好。各模型在同一B作品池内归一化，先预测视频再汇总到账号。

| 模型 | 测试账号损失 | 测试视频损失 |
|---|---:|---:|
| 账号均匀 | 6.74406 | 6.85173 |
| 视频均匀／线性数量 | 6.75992 | 6.86759 |
| 来源拟合的线性数量＋反馈＋年龄 | 6.55461 | 6.65404 |
| 来源拟合的自由数量＋反馈＋年龄 | 6.53443 | 6.63386 |
| A账号残差迁移 | 6.49790 | 6.59733 |
| A迁移但固定线性数量 | 6.50369 | 6.60312 |
| B自身账号历史 | **5.43615** | 5.53559 |
| B自身逐作品历史 | 5.43740 | **5.49875** |

| 成对比较（前者−后者） | 损失差 | 条件账号聚类重采样95%区间 |
|---|---:|---:|
| A迁移−内容基准 | −0.03653 | [−0.09682, 0.02490] |
| A迁移−固定线性数量的A迁移 | −0.00579 | [−0.02247, 0.01311] |
| B逐作品历史−A迁移 | −1.06050 | [−1.23757, −0.87181] |

区间只反映固定拟合预测、固定候选池下按整账号重采样的敏感性，不涵盖日期/观看者依赖、重拟合、候选池选择或因果参数不确定性。没有逐曝光iid重采样，也没有把seed和滚动起点当独立复制。

三个时间起点的A迁移损失分别为6.48534、6.49780、6.51471，相应内容基准为6.52558、6.53900、6.53968。点改善方向相同，但均小于目标自身记忆的优势。不能将两种损失改善的比例解释为“多少百分比流量由作品/账号因果决定”。

## 身份负对照与影响诊断

200次预定的账号身份错配，在作品数量（截断3）、时长与上传时间元数据组内进行。同一切分的映射跨时间起点固定；每个错配都重新按相同B校准规则选kappa/delta。错配平均损失6.53215，范围6.52659..6.53502；正确映射6.49790，低于全部200次错配。

这是观测性负对照，不是随机分配身份的因果p值。分箱没有控制全部需求、题材、质量或受众，也不能保证账号在箱内可交换；它只支持“正确配对比这一组同复杂度错配更有预测性”。不能据此认定不可转移账号资本。

在读取主结果后，追加了明确标记的固定预测影响诊断，没有重拟合或更换主模型：

- 849个账号中，678个在测试作品上有记录曝光；121个账号的成对损失分子改善，557个变差。这些是预测误差，不是作者的实际收益或福利。
- 曝光最高的10个账号占16.81%的评价曝光。评价时排除最高1个账号的损失贡献，A迁移仍改善−0.01921；排除最高5个或10个账号的贡献，差值变为+0.01335、+0.01342，即反而变差。其余概率未重新归一化，也未重拟合；这不是移除大账号后的新市场反事实。
- 逐一删除任意一个有曝光账号时，差值范围仍为−0.04200..−0.01921。整体不是单一账号完全驱动，但对少数高曝光账号组合敏感。
- 九个测试日中八日点改善，一日约+0.000054；短时间窗不足以推断长期资本持久性。

这些诊断解释了“平均小幅改善”和“账号区间跨零”为何可以同时成立。不能只展示聚合负对照，省略账号异质性与集中度。

## 数量假说与参数解释

允许数量指数自由变化，在迁移模型中的额外损失改善仅−0.00579，区间跨零。没有得到稳健的增量证据。来源拟合alpha范围.05..0.63866，中位数.28456；与V3不同候选池的约.71并非同一结构估计，不能据此声称平台政策改变。44/60个来源拟合的gamma在边界（主要为0），说明这些短窗/固定池内部分参数信息有限。

全部60个自由基准拟合及60个线性基准拟合成功结束，但优化器收敛不意味着结构参数识别。固定n_a与自由账号截距完全混淆；这个检验只比较受限预测形式，未估计控制全部账号异质性后的生产回报。入选作品数也不是完整产量，更不是新生产流量。

## 对理论的修正

1. 将持续作品/创作者差异作为基准模型必须容纳的对象；避免把历史份额胜出直接命名为账号资本。
2. 将新旧账号权重比r保留为情景参数，不用本轮残差迁移校准r；A/B仍在同一真实账号上，未发生身份迁移。
3. 持续类型theta与账号状态H仍需并列，现有数据无法判定优势是否随人转移。
4. 新生产n、可推荐库存Q和旧作品状态分别计量；本固定池检验主要针对旧作品的短期曝光。
5. AI生产成本、owner、真实开新号及平台历史奖励均没有由本轮未观测AI使用的历史数据识别。V4均衡只保留其条件命题地位。
