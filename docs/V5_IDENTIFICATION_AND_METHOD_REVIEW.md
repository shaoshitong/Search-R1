# V5 跨作品预测：独立研究设计与识别边界审查

审查日期：2026-11-05（北京时间）。这是执行前的方法建议，不是新增检验结果；没有修改主分析代码或下载原始数据。当前任务是检验：**一个账号在部分旧作品上的训练期曝光，是否包含能预测该账号其他旧作品未来曝光的信息？**

即使答案为是，也只能先称为“同账号跨作品的预测信息”。创作者持续类型、账号受众与匹配状态、题材组合等都可能产生该现象；不能把它直接命名为可随真人迁移的θ，或不可随账号迁移的H。[Heckman原章§3.1、§3.13](https://eml.berkeley.edu/discrete/ch3.pdf)支持这种状态依赖与未观测异质性的区分，但没有研究本项目的创作者拆号。

## 一、比较单位与归一化

建议以**B作品池内的作者曝光份额**为主结果，同时报告作品层面的结果。模型先给B中的每个视频一个预测权重，再在同一个B候选池内归一化；作者预测份额是其B视频预测概率的和。这样作者与作品指标来自同一预测，避免两套分母混用。

记测试日期t的视频曝光为y_vt，Y_it=Σ_{v∈B_i}y_vt，π_vt为视频预测概率，p_it=Σ_{v∈B_i}π_vt。报告：

- 作者层面曝光加权log loss：−Σ_it Y_it log p_it / Σ_it Y_it；
- 视频层面曝光加权log loss：−Σ_vt y_vt log π_vt / Σ_vt y_vt；
- 相同日期、相同候选池上的paired loss差，并辅以每日份额total variation；零测试曝光账号数单独报告。

作者均匀与视频均匀不是同一基线：前者p_i=1/A，后者p_i=n_iB/Σ_jn_jB。**必须保留视频均匀基线**，否则“账号历史信号”可能只是在恢复B中不相等的作品数。不得将B池条件份额描述成账号获得的全平台曝光份额。测试日实际总曝光可用于计算损失权重，不能偷偷用作待预测的未来总量特征。

## 二、A/B划分与固定样本

1. 在训练前已经确定的候选池中，以稳定`author_id`选出至少有两部入选视频的账号；Root当前计划的849个账号须由实际元数据复核。不得按未来曝光是否为正筛选。
2. 对每个账号，用固定seed的伪随机排序或SHA256(seed, author_id, video_id)排序后平衡切半，保证A和B均非空、数量差至多1；记录实现及seed。不能直接hash%2后删除单边为空账号：两作品账号会大量丢失，样本还随seed改变。
3. A/B只是在分析中隐藏不同作品，真实平台上的发布账号并没有改变；这不是拆号处理或身份迁移实验。预先固定5–10个seed，例如0–9；同一个seed的划分贯穿所有时间起点。可补做B→A，作为方向敏感性，不将两个方向当独立样本。
4. 保留无A训练普通曝光的账号，使用共同收缩先验，不因历史稀疏而删除。报告每侧视频数、训练曝光、随机反馈观测数、内容年龄和时长的分布，以及两侧差异。
5. 多作品账号是特殊子群；结果不能外推到单作品账号、全平台创作者或经济owner。

## 三、账号信号必须先处理数量、年龄和反馈差异

A的原始作者曝光份额同时承载A作品数、年龄、反馈与账号信息。平衡切半不能完全消除这种偏差，尤其奇数作品账号仍有n_A≠n_B，作品质量也不会严格平衡。

推荐的简单实现是先拟合共同的数量／随机反馈／年龄baseline。令A训练期某作者的实际曝光为Y_iA、baseline预期曝光为M_iA，构造收缩后的账号乘数：

\[
\widehat w_i^A=\frac{Y_i^A+\kappa}{M_i^A+\kappa},\qquad\kappa>0.
\]

κ的单位是曝光数，乘数向1收缩。对B中视频使用同口径基础权重b_vt，例如数量、需求代理和年龄模型，再预测：

\[
\widehat\pi_{vt}^{B}
=\frac{\widehat w_i^A b_{vt}}
{\sum_j\sum_{u\in B_j}\widehat w_j^A b_{ut}}.
\]

该公式是建议的预测诊断，不是平台实际规则。若先执行更简单版本，至少校正A的每视频曝光，再乘上B的作品数／基础权重；原始A份额可另列diagnostic，不宜作为唯一“作者类型”测度。不要将原始份额、每作品曝光与baseline残差三种口径混称为同一变量。

随机训练曝光中的`long_view`只能作受观看者构成、时长和抽样误差影响的需求代理，不称为真实质量。应采用训练期共同的时长分组先验及收缩；稀疏或零随机观测的视频继续保留。所有模型使用相同q_v和年龄信息，不能只给其中一个模型额外的B视频需求特征。

## 四、最少比较模型与信息集

| 模型 | 使用的信息 | 作用 |
|---|---|---|
| 作者均匀、视频均匀 | 固定候选池及B作品数 | 区分单位与数量效应 |
| B数量／随机反馈／年龄 | 截止预测时点可得的B元数据及随机训练反馈；公共参数由允许的训练集拟合 | 不使用B普通曝光记忆的内容基线 |
| A跨作品乘数×B内容基线 | 上行信息＋A普通训练曝光 | 主检验：账号关联信息能否跨作品泛化 |
| B自身普通训练历史 | B训练期普通曝光，使用相同收缩规则 | 旧作品／账号记忆基准；并非未来oracle，但信息比盲测B更丰富 |
| B自身历史＋A跨作品信号 | 两种训练历史，公共组合权重仅在验证期选择 | 判断A是否在B自身记忆之外仍有增量信息 |

主跨作品模型不使用B的普通训练曝光估计逐账号乘数。为保持最清晰的信息隔离，可在A时间验证集选择κ及公共模型参数，主分析固定账号乘数指数为1。若使用B普通验证结果选择公共组合参数，必须明确披露；这没有直接读取未来测试结果，但不能再声称完全不使用B普通曝光。

B自身历史强于跨作品预测并不否定共同作者成分：B历史直接记住了目标作品，还可能更精确。反之，跨作品信号胜出也可能来自对B稀疏历史的降噪，不能单独证明账号资本。

## 五、时间窗口与滚动评估

一个可执行的主方案是5个预测起点：2022-04-28、04-30、05-02、05-04、05-06；各预测其后两天。起点前最近两天作验证，训练自04-22开始扩展；另作固定5日训练窗敏感性。这样主测试窗口不重叠，覆盖04-29至05-08。

每个起点都从头计算允许的训练历史、需求先验和参数；不能用全月统计表、未来随机反馈或测试结果选窗、选seed、选tab、选边界。冻结历史与衰减历史如需比较，应事先定义衰减网格并仅用验证集选择。时间窗口很短，折旧／长期资本持久性不能可靠估计。

主tab应在训练期按预先规则确定，并保持同tab比较。不同`tab`是场景及不同推荐策略，不能合并成一个共同曝光制度。KuaiRand随机候选池及参与者筛选见[原文§3.2](https://arxiv.org/html/2208.08696v1)；固定插入概率数值未公开，Pure也不包含完整用户序列。滚动起点评估的原则见[Tashman（2000）](https://doi.org/10.1016/S0169-2070(00)00065-0)，它改善预测比较，不提供因果识别。

## 六、身份置换检验

置换应在**作者层面**进行：把整套A账号乘数／特征作为一个block，重配到另一个账号的B视频集合；保持B视频、结果、年龄、随机反馈与数量不变。不能逐曝光或逐视频独立打乱身份，否则破坏原有组内结构。

建议同时报告全体置换与分箱置换。分箱至少固定(n_A,n_B)，再按训练前可得的年龄及需求代理作少量粗分箱；分箱方案及小箱合并规则预先确定。报告箱数、箱大小、可真正交换的账号比例，以及固定不动的账号数。不要为追求显著而反复改变分箱；极细分箱会使置换几乎不改变数据。

如果每次置换后仍重选公共超参数，应在相同的训练／验证时间规则下重跑整个选择流程；若只置换已拟合模型的乘数，就将其称为“给定拟合预测器的身份对齐placebo”。可作199次置换及固定随机种子，预先指定主loss差。

观测数据中的作者在箱内并不一定可交换：未观测题材、质量和受众仍可能不同。因此置换结果说明真实账号配对比所设负对照更有预测性，**不是随机分配账号身份的因果p值**，也不能证明跨账号所有权或H不可转移。

## 七、不确定性与bootstrap层级

- seed、A/B方向和滚动起点复用了相同视频、作者及观看者，不能把seed×origin当成几十个独立样本来计算标准误。先在相同测试日期／作者上平均seed与方向的paired loss贡献，再做区间；同时单列seed及origin范围。
- 主时间敏感性可用相邻2日和3日block重采样共同测试日期，每个抽样使用全部作者，且模型和基线始终成对。测试仅10天，有效独立时间块极少，区间应称探索性。
- 作者维度可整块重采样，保留其全部B作品及所有日期；这回答跨作者稳健性，不能替代时间相关性的处理。补充作者×日期双向重采样时，日期仍应成块。不要用逐曝光iid bootstrap获得虚假的百万级样本精度。
- 若在原固定候选池下仅重加权loss贡献，区间是给定拟合模型、给定候选池的预测敏感性；不包含训练参数不确定性。若把重采样解释为新市场／新候选池，必须重新归一化概率，并另行考虑重拟合，不可混用两种目标。
- 观看者重复出现在多个视频及日期，逐事件层面的推断还存在观看者依赖；作者／日期两层不能保证处理所有依赖。没有必要为本轮预测诊断声称一个精确覆盖率。

[Owen（2007），The pigeonhole bootstrap](https://doi.org/10.1214/07-AOAS122)针对推荐数据的交叉依赖说明逐记录bootstrap可能误导，并研究行列分别重采样。其结论不是“作者×日期block方法对本数据自动精确有效”；上述适配与短时间窗限制必须保留。

## 九、窄搜得到的迁移制度线索

[Mastodon官方迁移文档](https://docs.joinmastodon.org/user/moving/)提供一个有用的反例：正式profile move可以转移followers，但不能转移旧posts。账号资本应拆成可携带受众与不可携带历史等成分；“换号必然失去全部H”不是普遍事实。双向alias和Move可提供技术上的账号关联，但仍不等于已核实经济owner，也不使迁移时点外生。

[Bin Zia等，IMC2024原文](https://tysong.github.io/files/IMC24-Switch.pdf)，DOI [10.1145/3646547.3689027](https://doi.org/10.1145/3646547.3689027)，用官方API的`moved`字段研究8,745名迁移用户及迁移前后帖子。所查全文没有公开数据文件／代码下载入口；不是本轮已取得的数据。它也没有推荐impressions或AI生产成本随机化，因此仅是未来设计线索，本轮不扩大抓取或联系作者。

若第一行稳健，可保留“共享创作者／账号成分”的候选模型；θ可转移和H不可转移仍应并列为不同假设，用r等参数作情景分析。不要用一次跨作品预测把r校准成新旧账号权重比。若改善不稳健，应优先保留作品状态、内容年龄与更保守的异质性解释，而不是用更复杂博弈强行吸收所有误差。

## 十二、正式结果解释审查（DA checkpoint 2）
