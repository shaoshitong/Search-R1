# AI 内容平台数量激励与账号拆分的推导包

## Target

解释一个具体的课程研究问题：生成式 AI 降低内容生产成本后，平台通过压低单账号的数量回报控制内容供给，何时会把竞争转移到账号拆分？推导数量上限与不拆号能够同时实现的条件。

目标是一个应用博弈模型与条件命题。身份操纵、Tullock contest 和凹函数的拆分激励都有既有研究；本项目的新问题定位是这些因素在 AI 创作平台数量治理中的结合，而非宣称发现全新的基础理论。

## Status

COHERENT AFTER REFRAMING / EXTRA ASSUMPTION

主模型使用连续的标准化内容强度与连续账号数松弛。另给一个严格整数的二乘二切片。两个切片回答不同问题，不能把其结果直接混用。

## Invariant Object

创作者从固定曝光收益池获得的份额，以及为生产和身份所付出的总成本：

\[
u_i=R p_i-c n_i-\tau(k_i-1),\qquad
p_i=\frac{s_i}{s_i+s_j}.
\]

收益池体现用户注意力稀缺，不是无限按件补贴。

## Assumptions

1. 玩家为一个平台与两位经济意义上的创作者。观众提供固定注意力，不另设战略用户。
2. 平台先承诺推荐积分规则，创作者观察规则后同时行动；参数为共同知识。平台不能直接把多个账号归并为同一创作者。
3. 主模型固定内容质量相同。AI 可以降低生产成本，也可能提高质量；本切片只分析前一种通道。
4. 每个账号的内容强度为 x，积分为 x^alpha，0 < alpha <= 1。alpha 越小，同账号追加内容的边际积分越低。
5. 两位创作者对称，生产成本为 c n_i，c > 0。额外账号成本为 tau(k_i-1)，tau > 0。参与和原始账号给定，不分析进入、退出和新创作者的验证负担。
6. 主模型 n_i 是连续标准化内容强度，k_i >= 1 是连续松弛；不把 n_i 当作必须大于 k_i 的字面作品件数。实际整数问题另行计算。
7. 若使用 n_i = 0 的边界，零内容账号积分定义为零；双方都无内容时不发放收益。下述均衡处 n_i > 0。

## Notation

| 符号 | 含义 |
|---|---|
| R > 0 | 固定曝光的总收益，以统一效用单位计 |
| c > 0 | 单位标准化内容的生产成本 |
| alpha in (0,1] | 平台设定的同账号数量回报弹性 |
| n_i | 创作者 i 的总内容强度 |
| k_i >= 1 | 创作者 i 的账号数量，主模型为松弛变量 |
| tau > 0 | 每个额外账号的私人成本 |
| s_i | 创作者旗下所有账号的总推荐积分 |
| n_bar > 0 | 平台给定的每位创作者均衡产量上限 |
| v >= 0 | 平台验证政策带来的额外身份成本增量 |

## Derivation Strategy

先由每账号积分推导总积分，解创作者子博弈，再把数量上限与不拆号约束代入平台设计问题。最后用固定两件作品、最多两个账号的整数博弈展示激励。

## Derivation Map

1. 凹积分规则使同一创作者均分内容能够最大化其账号总积分。
2. 总积分决定曝光份额，曝光份额与成本决定最优反应。
3. 对称均衡给出产量和身份的不同反应方向。
4. 平台的两项政策约束形成 alpha 的上下界。
5. 固定产量的整数切片检验拆号激励，不用于证明数量变化。

## Main Derivation

### Step 1 积分聚合

给定总强度 n_i 与账号数 k_i，凹性使均分内容成为积分最大化分配。于是

\[
s_i=k_i(n_i/k_i)^\alpha
   =k_i^{1-\alpha}n_i^\alpha.
\]

alpha = 1 时积分与拆分无关；alpha < 1 时，固定总内容而增加账号会提高积分。这是既有 false-name / Sybil 问题在本积分规则中的体现。

### Step 2 连续子博弈的均衡

给定对手积分 S > 0，函数 R s/(s+S) 对 s 递增且凹；Cobb–Douglas 积分对 (n,k) 凹。复合后扣除线性成本，收益对自己的两个选择联合凹，因此满足约束的一阶条件足以验证最优反应。

记 M_i = R p_i(1-p_i)。生产的一阶条件为

\[
\frac{\partial u_i}{\partial n_i}
=\frac{R s_j}{(s_i+s_j)^2}\frac{\alpha s_i}{n_i}-c.
\]

这一步必须对分母同样使用链式法则。整理得

\[
c n_i=\alpha M_i.
\]

若 k_i > 1，身份的一阶条件为

\[
\tau k_i=(1-\alpha)M_i.
\]

若 k_i = 1，身份的边界条件为 tau >= (1-alpha) M_i。

因为两人份额相加为一，M_1 = M_2，生产条件给出 n_1 = n_2。一人拆号而另一人处于单号边界会同时要求 tau < (1-alpha)M 与 tau >= (1-alpha)M，因此不可能。两人账号数相同，继而 p_1 = p_2 = 1/2。得到连续模型的均衡：

\[
\boxed{n^*=\frac{R\alpha}{4c}},\qquad
\boxed{k^*=\max\left\{1,\frac{R(1-\alpha)}{4\tau}\right\}}.
\]

alpha = 1 时 k*=1，n*=R/(4c)。主模型不取 alpha=0，以避免零内容边界的退化。

### Step 3 比较静态与一个反例

在拆号内部区，降低 alpha 使 n* 下降、k* 上升。数量治理会把一部分竞争转向身份。

固定 alpha 与 tau，降低 c 提高 n*，却不改变 k*。因此本模型不支持“AI 越便宜，账号必然越多”；AI 的作用是使既定数量目标更难实现。

内部拆号区还有

\[
cn^*+\tau(k^*-1)=R/4-\tau.
\]

此时改变 alpha 重新分配两种竞赛成本，但不改变创作者的总策略成本。这个结论依赖齐次积分与线性成本。

### Step 4 数量上限与不拆号的可执行条件

要求 n* <= n_bar 且 k*=1，等价于寻找

\[
1-\frac{4\tau}{R}\le\alpha\le\frac{4c\bar n}{R},
\qquad 0<\alpha\le1.
\]

由于 c、n_bar 均为正，可行的充要条件为

\[
\boxed{c\bar n+\tau\ge R/4}.
\]

这是连续松弛模型内的命题。它说明生产成本下降会缩小平台同时限制产量、维持单账号策略的可行范围。它不是从真实平台数据估计得到的事实。

### Step 5 平台先行动的闭合

平台将 n_bar 作为审核或供给治理目标。设原身份成本为 tau_0 > 0，验证选择 v >= 0 使 tau = tau_0+v。平台最小化验证资源成本 K(v)=kappa v^2/2，kappa>0，约束为上述产量目标与单号均衡；alpha 是其同时选择的规则参数。

于是

\[
\boxed{v_{\min}=\max\{0,R/4-c\bar n-\tau_0\}}.
\]

约束绑定时，可取 alpha*=4c n_bar/R。验证成本如何转化为账号的私人成本，是需要后续校准的政策假设。此目标是约束下的成本最小化，不等同于已经求出了平台利润或社会福利最优。

### Step 6 精确整数切片

固定每人两件作品，选择单号 N 或双号 D，允许 alpha in [0,1]。令 b=2^alpha。单号积分为 b，双号积分为 2。

| 自己策略 | 对手 N | 对手 D |
|---|---|---|
| N | R/2 - 2c | Rb/(b+2) - 2c |
| D | 2R/(b+2) - 2c - tau | R/2 - 2c - tau |

无论对手策略如何，拆号净增益都为

\[
g(\alpha)-\tau,\qquad
g(\alpha)=\frac{R(2-2^\alpha)}{2(2+2^\alpha)}.
\]

- 0 < tau < g：拆号严格占优，唯一均衡 (D,D)。双方各比 (N,N) 少得 tau，形成囚徒困境。
- tau > g：单号严格占优，唯一均衡 (N,N)。
- tau = g：双方对自己两种策略均无差异，所有混合策略组合都是均衡。
- tau = 0 < g：拆号仍严格占优，但双方终态收益不低于共同不拆号，不能称严格囚徒困境。

例如，R=12、alpha=0、tau=1 时，去掉双方共同的生产成本，收益矩阵为 (6,6)、(4,7)、(7,4)、(5,5)。这些是说明模型的假设参数，并非实测数据。

## Remarks and Interpretation

本项目可展示的核心论点是：平台应同时考虑“每条内容的生产成本”和“每个新身份的成本”。只压缩同账号数量回报，可能保留总竞赛支出而改变它的去向。

理论预测需与实证证据分开。公开账号不能识别同一真人，提示词相似也不能证明账号同属一人。数据可用于描述产量分布、内容相似性与互动集中度，并为政策模拟提供情景；不能凭这些变量认定现实中存在拆号操纵。

## Boundaries and Non-Claims

- 连续 k 的均衡不等同于实际整数账号均衡；完整的整数与内生产量模型需单独枚举或求解。
- 固定两件作品的切片不支持“政策降低产量”的结论。
- 质量、真实性、点击量和货币收益不是同一个变量；本基准未内生化质量。
- n_bar、c/R、tau/R 和验证技术未从公开互动数据中得到识别。
- 不分析用户需求扩张、创作者进入退出、异质能力、处罚误伤或平台竞争。
- 未证明原创理论优先权；已有 Sybil 与 contest 文献必须引用。

## Open Risks

1. 线性成本与齐次积分可能使比较静态过于整齐。执行阶段优先比较凸成本与整数账号。
2. 按账号压缩实际未必是平台的真实推荐规则，应将其写为待比较的机制。
3. 新账号验证也可能伤害真正的新创作者；当前参与固定的模型不能评价该损失。
4. AI 效应通过 c 进入，属于生产率变化的通用机制；需要用具体平台制度与数据动机说明应用价值。
