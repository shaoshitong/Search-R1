# 第三轮：新增公开数据与真实曝光检验

核验日期：2026-11-04。定位：课程研究项目。结论来自实际数据分析，不是用预先设定的曝光公式生成的模拟结果。

**目前的证据是混合的。** KuaiRand的一个推荐场景中，凹数量模型对留出曝光有小幅预测增益；KuaiRec选定日面板没有提供同样支持。两者都是历史非AI视频数据，而且历史曝光份额的预测都明显更好。因此，原博弈模型仍是条件性理论基准，尚未成为经过实证验证的AI创作者博弈。

## 2. 检验目标和统计模型

检验的是原博弈中“账号数量分配函数是否可作为现实曝光的近似”，不是直接估计生产成本或求出实际玩家的纳什均衡。

设固定候选池中，账号a有n_a个视频。基准预测是：

\[
\widehat p_{ad}=\frac{n_a^\alpha}{\sum_b n_b^\alpha}.
\]

加入观看反馈代理与年龄后，预测分数为：

\[
w_{ad}=n_a^{\alpha-1}\sum_{v\in a}q_v^\beta(1+\mathrm{age}_{vd})^{-\gamma},
\qquad \widehat p_{ad}=\frac{w_{ad}}{\sum_b w_{bd}}.
\]

当所有视频的q和年龄相同时，它退化为原来的n_a^alpha。这里的n仅为选中候选池库存；不是创作者全部生产量。q是所选观看者的长观看反馈代理，不能称为作品的内在质量。

同时比较：账号均匀分配、线性数量、凹数量、正区间自由数量、分别加入反馈与年龄的三个版本，以及历史曝光份额。凹模型限制0.05≤alpha≤1；自由模型限制0.05≤alpha≤2，**没有检验非正alpha**。beta在[0,4]、主分析gamma在[0,2]。各模型只在训练期拟合；验证期选择；测试结果不用于拟合。

测试损失为每次曝光的交叉熵，单位nats，越低越好。总变差另存原始审计JSON。按测试日聚类重采样2,000次，只描述固定模型与样本下的日波动，不覆盖拟合误差、样本选择、时间序列依赖或因果识别。不同数据集的损失不可直接横比。

## 3. KuaiRand：一个场景提供小幅支持

固定2022-04-22之前已上传的全部7,583个候选视频；作者账号6,510个，其中849个在池中有多个视频，86.96%只有一个。没有用月度视频统计特征，也没有根据测试期是否获得曝光来删账号。

- 训练：2022-04-22至26；验证：04-27至28；测试：04-29至05-08。
- 按普通训练日志数量选择前三个tab。只有tab=1具有足够的同场景随机曝光；tab=0、4没有随机训练/验证记录，未宣称跨场景复制。
- tab=1普通曝光：训练72,137条、验证20,535条、测试130,841条；1,878个候选作者账号测试期没有记录到普通曝光，仍保留为零记录曝光。
- q只由同场景203,601条随机训练曝光估计，用81,528条随机验证曝光选择收缩强度。随机验证长观看log loss为0.27094，优于全局均值0.27964和仅时长分组先验0.27897。71个视频没有随机训练曝光，使用先验收缩。

| 模型 | alpha | 测试损失 |
|---|---:|---:|
| 线性数量 | 1.000 | 8.76222 |
| 凹数量 | 0.701 | 8.75483 |
| 线性数量＋反馈＋年龄 | 1.000 | 8.55106 |
| 凹数量＋反馈＋年龄 | 0.711 | 8.54456 |
| 历史曝光份额 | 不拟合alpha | **7.61506** |

凹数量相对线性的损失差为−0.00739；加入反馈/年龄后为−0.00651，按测试日重采样区间约[−0.00775,−0.00519]。这属于小幅条件预测改进，不能把区间解释为“平台因果alpha<1”的证明。另一指标并未改善：加入反馈/年龄的凹模型总变差0.59480，略差于线性版本0.59419；历史份额为0.25555。不能据单个指标宣布全面胜出。历史份额在验证期已胜出，测试期也明显更好；原数量模型遗漏了大量持续性异质性。

主模型gamma撞2的上界，随后做了明确标记的**事后敏感性诊断**：固定同一池、同一q、同一tab，只改gamma上限，仍只在训练期拟合，没有按测试结果选择或替换主模型。

| gamma上限 | 凹反馈年龄模型alpha | 拟合gamma | 测试损失 |
|---|---:|---:|---:|
| 0（无年龄项） | 0.7312 | 0 | 8.54760 |
| 2（主分析） | 0.7107 | 2.0000 | 8.54456 |
| 4 | 0.7045 | 2.5773 | 8.54427 |
| 8 | 0.7045 | 2.5773 | 8.54427 |

在这些设定中alpha没有因年龄上限放宽而消失，但这仍不是新确认性验证。计算使用先减最大log权重再指数化，避免原始分数截断破坏尺度不变性。稳定数值版本与初始主分析的最大测试损失差为1.48×10^-8，实质结论不变。

[KuaiRand论文](https://arxiv.org/html/2208.08696v1)说明了候选池过滤、随机插入和观看者筛选。随机候选视频均匀抽取，因此“随机曝光随候选库存线性增长”本身是实验设计结果，不能作为博弈理论验证。本轮预测目标是普通曝光，而不是把这个设计事实当发现。

## 4. KuaiRec：未复现凹数量支持

原数据有842条明确show_cnt=0记录；没有记录的视频×日期可能是缺失，不能补成零。为此选取63天每天都有记录且首日之前已上传的925个共同视频，形成58,275行平衡面板，覆盖867个账号；只有46个账号含多个视频，库存最大4。**共同面板根据未来是否存在记录形成**，所以这叫回顾性固定面板的时间留出预测，不能称严格前瞻验证。

训练为07-05至08-03；验证为08-04至15；测试为08-16至09-05。q来自普通推荐训练期的长观看/曝光统计，不是随机需求代理，仍存在曝光选择偏差。测试期selected-item show_cnt合计187,688,987；这不是等量独立玩家或行为选择样本。

| 模型 | alpha | 测试损失 |
|---|---:|---:|
| 线性数量 | 1.000 | 6.70880 |
| 凹数量 | 1.000（上界） | 6.70880 |
| 正区间自由数量 | 2.000（上界） | 6.73250 |
| 线性数量＋反馈＋年龄 | 1.000 | 7.28128 |
| 凹数量＋反馈＋年龄 | 1.000（上界） | 7.28127 |
| 自由数量＋反馈＋年龄 | 1.620 | 7.24910 |
| 历史曝光份额 | 不拟合alpha | **5.21434** |

不能笼统声称“超线性更好”：纯数量自由模型在测试期反而比线性差；只有加入反馈/年龄的自由模型比相应的受限版本好，而且仍远差于历史份额。两个受限反馈年龄模型都在alpha=1，约6×10^-6损失差是优化数值误差，**不能被重采样区间包装成凹模型改善**。

因此，这组数据没有支持数量压缩假设，也不能识别平台因果上的超线性奖励。46个多视频账号不能因为拥有大量曝光计数而变成充分的独立数量变化。

## 5. 对当前博弈理论的影响

原理论的玩家、策略和收益仍是：平台先设alpha与验证成本v，两个创作者选择内容量n与账号数k，账号等分时分数为k^(1−alpha)n^alpha，收益为R乘曝光份额，扣除cn与tau(k−1)。tau=tau0+v。保留k≥1、先忽略n≥k约束时，连续松弛解为n*=R alpha/(4c)、k*=max{1,R(1−alpha)/(4tau)}；仅在它满足物理约束时直接使用，否则采用V2的可行域/整数修正。这些都是**在既定假设下的数学结论**。

本轮数据检验的是上述曝光分数的一个必要现实近似，没有识别以下关键对象：

1. AI使用与外生生产成本变化c；
2. 同一经济主体控制的多个账号及其真实k；
3. 新账号成本tau、收益池R与可归属创作者的真实收入；
4. 创作者面对规则变化时的反应，以及平台的目标函数；
5. 保持质量、受众与其他状态不变时，增加内容或拆账号的因果收益。

故不能将本轮结果称为验证了AI导致刷量、实际拆号、纳什均衡或验证成本政策。把拟合alpha=.71直接代入博弈公式，再拿同批数据宣布均衡成立，会混淆预测参数与结构参数。

课程项目现在可以提出更准确、可证伪的问题：**账号级数量压缩在什么条件下抑制供给膨胀，又在什么条件下诱发身份拆分？历史流量和新账号劣势会怎样改变门槛？** 历史份额的预测优势支持考虑持久异质性或状态变量；它本身不能证明历史曝光具有因果作用，也可能反映持续的质量、受众或选样差异。

不建议仅为获得正面结论继续叠加相似图库样本。下一步直接验证博弈机制，优先级更高的是已知owner、可控成本与有报酬的实验，随机改变生产工具成本、数量分配规则和新账号成本，观察真实n、k及收益。LLM模拟可以检查算法或推导，不能替代真人行为证据。实验尚未实施，不在本轮结果中虚构样本或检验功效。

## 6. 开源数据与爬虫结论

已找到并实际使用公开数据，所以先走可复现的公开元数据路线。另检索到的AI平台浏览计数源及不完整候选，见[公开数据目录](V3_OPEN_DATA_CATALOG.md)和对应审计；浏览计数不能自动当推荐impressions。

SeaArt的8个纯元数据文件合计16,904,683字节，固定commit为`4321a586faf084ddfa6ab415caae4073af13aa67`；没有下载媒体或访问元数据中的媒体URL。按作品ID去重后57,851行，其中33,303行的like计数大于view计数，17,387行view=0但like>0；所有like至少为2，不能排除选择性收集。由此不能把like/view当概率。该浏览计数没有文档支持其等于推荐曝光；`created_at`按Unix毫秒解析为2023-09-05至2024-06-24，但上传/采集语义未核实。全部NSFW编码为2，映射未说明，不宣布SFW。数据卡没有声明许可，仍只分发小型汇总。该源提供AI平台背景材料，未增强作者博弈的直接识别。

核验了Civitai官方公开images/posts/users文档、官方CLI与第三方采集器。Mac侧TLS失败，HKUST3侧连接超时，状态均为HTTP000；没有取得首批live数据或两次快照，也没有读到robots内容。这里不能说收到403/429，更不能说已确认允许抓取。官方images接口文档也没有提供推荐曝光分母；即使访问恢复，重复采集反应计数仍不能直接补出曝光。

带相关字段的Pixiv 2026数据需要共享Hugging Face账号资料，其他部分数据需要申请；本轮没有接受这些条件，没有借镜像绕过门禁。未来可在接口可达时记录稳定作品ID、稳定账号ID、每次请求UTC及指标，建立两次以上同作品面板，但它仍不自动解决owner和成本的识别。

原始数据、逐曝光日志和中间表全部留在HKUST3的`/data/shaoshitong/ai_creator_game_20261104/v3/`。本地仅保留源码、必要文档和小型审计。最终数值见`V3_AUDIT/`，方法复核见`V3_METHOD_REVIEW.md`；源码备份与远程SHA验收见`CODE_PUBLICATION_V3.json`。
